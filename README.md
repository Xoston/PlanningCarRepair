# Система планирования технического обслуживания автомобиля

Простой инструмент на Python для учета автомобильных сервисных задач, отслеживания сроков ТО и контроля пробега.

## Функционал
- Хранение информации об автомобиле (марка, модель, год, текущий пробег).
- Добавление задач по обслуживанию (замена масла, фильтра, тормозных колодок).
- Установка дедлайнов по дате и по достижении определенного пробега.
- Просмотр списка предстоящих и выполненных работ.
