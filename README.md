# Система планирования технического обслуживания автомобиля

## Назначение
Консольное приложение для отслеживания сроков проведения технического обслуживания (ТО) автомобиля на основе текущего пробега и даты.

## Целевая аудитория
Автовладельцы, желающие своевременно получать уведомления о необходимости замены расходных материалов и прохождения сервисного обслуживания.

## Предметная область
Техническое обслуживание автотранспорта (замена масла, фильтров, тормозных колодок, плановые осмотры ТС).

## Основные сущности
- Автомобиль (марка, модель, текущий пробег)
- Сервисная задача (название, целевой пробег, плановая дата)
- Статус обслуживания (актуально, требуется ТО, просрочено)

## Основные функции
- Расчет оставшегося пробега до планового ТО.
- Проверка статуса необходимости проведения обслуживания по дате и пробегу.
- Формирование и вывод итогового отчета о состоянии автомобиля.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
